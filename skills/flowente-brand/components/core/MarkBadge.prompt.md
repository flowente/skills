The brand's signature composition: a solid accent shape behind a boiling Flow Mark that overflows the shape's perimeter. Used in hero, feature sections, and card thumbnails.

```jsx
<MarkBadge mark="coil" shape="square" boxW={340} boxH={230} shapeSize={190} markW={340} markH={230} rotate={6} />
```

Mark should always be LARGER than the shape (it must overflow). Requires `<SvgFilters />`.
