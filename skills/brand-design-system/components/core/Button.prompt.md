Flowente button: primary = solid ink on paper; ghost = transparent with hairline border. Hover is a 1.02 micro-zoom. Flow Blue is NEVER used on buttons.

```jsx
<Button href="#" size="lg">Parliamone</Button>
<Button variant="ghost">Come lavoriamo</Button>
```

Variants: primary | ghost. Sizes: md | lg. No default arrows or icons.
